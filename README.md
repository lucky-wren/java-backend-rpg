# Java 后端勇者闯关

> 把两份 Java 后端手册变成一条能打怪升级的路。**单文件静态页面，零构建、零依赖、零 CDN**，双击就能玩，也能直接部署到 GitHub Pages / 腾讯云静态托管，还能装到手机主屏幕离线刷。

## 这是什么

题库取自：

- 《Java 后端开发实战手册：从零到五年》—— 22 个领域 / 201 关 / 网约车平台场景
- 《Java 后端 2→5 年进阶实战手册》—— 智能工厂 MES 主线 + 业财一体化辅线

**90 关**，按 ★1 → ★5 循序渐进，围绕四个目标设计：

| 目标 | 怎么落地 |
| --- | --- |
| 懂原理 | **每关一份只讲这一题的精讲**：本题考什么 → 起因 → 机制逐层推导（含 ASCII 图）→ 真实场景 → 本题踩坑表 → 面试 30 秒怎么说 → 面试官追问 |

## 题库编排 · 从 ★1 到 ★5 的 5 幕 14 章

题库是**一条全局单调曲线：5 幕 / 14 章 / 90 关**，难度序列 `19×★1 → 27×★2 → 20×★3 → 15×★4 → 9×★5`。三条主线（Java 底座 / 工程与数据 / 业务与交付）逐幕螺旋上升，每幕只含一个难度档，开头写明「这一幕要具备什么能力 / 前置是什么 / 出关能做到什么」。

| 幕 | 能力目标 | 关数 | 章节（按知识依赖排序） |
| --- | --- | --- | --- |
| ACT 1 ★1 | 认得出：概念 / 手册口径 / 领域名词 | 19 | Java 底座最小认知 → 工程与数据概念速认 → 业务与交付第一张图 |
| ACT 2 ★2 | 写得出：判空 / 金额 / SQL / 分录一次写对 | 27 | 写对每一行 → 工具与算法落地 → 第一笔分录与防御 |
| ACT 3 ★3 | 懂原理：按「起因→机制→边界」推导 | 20 | 机制推导 → 存储与消息机制 → 领域不变量 |
| ACT 4 ★4 | 扛得住：并发事故 / 线上排障 / 防御性代码 | 15 | 并发事故与排障 → 线上边界与防御 → 领域深水区 |

- **难度按每题需要的认知层级标定**：认名词的题（MES 三层、借贷恒等式）放 ★1；单行写法（`Objects.equals` 判空、`BigDecimal` 金额、条件更新 SQL）放 ★2；需要推导机制的题（HashMap 0.75 与树化阈值 8、volatile 边界、深分页）放 ★3；并发事故定位与防御性代码放 ★4；表驱动状态机、缓存一致性、分布式锁与 BOSS 会战放 ★5。代码关按幕分层 1 / 3 / 4 / 4 / 2，★1 只有「打印第一行日志」。

- **内容组织**：90 份逐题精讲、14 个代码关判分、11 份体系课全部按 id 绑定；讲义页按幕分组，体系课按题目所属主题索引。

| 功能 | 说明 |

## 快速开始

### 只要静态页面（最简单）

```bash
# 直接双击 index.html，或
python3 -m http.server 8000
# 打开 http://localhost:8000/
```

### 要真编译（推荐）

```bash
python3 javac_server.py          # 需要 JDK 8+，Python 3 标准库即可，无第三方依赖
# 打开 http://127.0.0.1:8787/   ← 服务顺带同源托管页面，状态灯自动 🟢
```

连上之后，代码关、讲义示例、项目工坊的代码都是**真的 `javac` / `java`** 编译运行，展示真实 `stdout / stderr / compile_output` 与耗时。没装 `javac` 也能跑：JDK 11+ 用 `java Xxx.java` 源码模式，多文件自动合并。

## 📱 把游戏装到手机主屏幕

装到主屏幕后是**全屏、无地址栏、有独立图标**的 App 形态；首次联网打开会缓存全部资源，之后地铁、飞机上断网也能答题、看精讲、写代码。

**前提：必须有一个 `https://` 网址。** 直接双击本地 HTML（`file://`）或 `http://127.0.0.1:8787/` 打开时，浏览器不提供「安装」能力，本机地址手机也访问不到。先按下面「部署」拿到 https 地址。

### 第 0 步 · 把网址弄到手机

页面「📖 玩法 & 部署说明 → 📱 把游戏装到手机主屏幕」里有一个输入框：填入部署好的 `https://` 地址 → 点「📱 生成二维码」→ 手机相机或微信「扫一扫」扫码 → 若是在微信里打开的，点右上角 **···** →「**在浏览器打开**」（微信内置浏览器不能直接安装）。也可以直接把链接发到「文件传输助手」，或手机浏览器手输网址。

### iPhone / iPad（iOS 16 及以上，必须用 Safari）

1. 用 **Safari** 打开 https 地址，等页面完全加载（首次缓存离线资源，约 2~3 秒）。
2. 点屏幕**底部正中间**的「分享」按钮：方框带向上箭头 ⬆️（iPad 在右上角）。
3. 在弹出菜单里**向下滑动**，找到「**添加到主屏幕**」（Add to Home Screen，图标是 ⊕）；有些系统要翻到第二屏。
4. 可改名称（默认「勇者闯关」），点右上角「**添加**」。
5. 回主屏幕就能看到图标；点开是**全屏、无地址栏**。
6. 长按图标可移动；改名只能删掉重新添加。

> iOS 上 Chrome、QQ 浏览器、微信内置浏览器**都装不了**，必须用 Safari。找不到菜单项时依次检查：是否用了**无痕模式**（无痕下禁用）、网址是不是 `https://`、`设置 → 屏幕使用时间 → 内容和隐私访问限制` 是否限制了主屏幕改动。

### 安卓（Chrome / Edge / 三星浏览器）

1. 用 **Chrome** 打开 https 地址，停留 2~3 秒。
2. 两种方式任选：① 底部弹出「**安装应用**」横幅 → 点「安装」；② 右上角 **⋮** →「**安装应用**」/「**添加到主屏幕**」（版本不同叫法不同，在菜单中部）。
3. 弹窗点「安装」/「添加」，图标出现在桌面或应用抽屉。
4. 小米 / 华为 / OPPO 等 ROM 可能追问「是否允许创建桌面快捷方式」，选**允许**。
5. 找不到菜单项时：⋮ →「应用」→「安装此站点」；Chrome 版本建议 ≥ 89。

> 在微信 / QQ 里打开的：右上角 **···** →「**在浏览器打开**」，跳到系统浏览器后再按上面做。

### 电脑（Windows / macOS，Chrome / Edge）

1. Chrome 打开 https 地址，地址栏**最右端**出现 ⊕ / 显示器带下箭头的「安装」图标 → 点它 →「安装」。
2. 或右上角 **⋮** →「投屏、保存和共享」→「**安装页面为应用**」（Edge 是「应用」→「将此站点安装为应用」）。
3. 装好后是独立窗口，可从开始菜单 / 程序坞 / Spotlight 直接启动。

### 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 找不到「添加到主屏幕」 | 多数是用了非 Safari 浏览器或在微信内打开：换 Safari / 点「在浏览器打开」；再检查是否无痕模式。 |
| 提示「无法安装此页面」 | 网址不是 https、证书无效，或 `manifest.webmanifest` 没传到根目录。 |
| 装完打开白屏 | 清一次离线缓存再联网打开；确认 `sw.js`、图标与 `index.html` 在**同一目录**。 |
| 图标是网页截图 | `icon-192.png` / `icon-512.png` 没上传到根目录，补传后重新添加。 |
| 换手机进度没了 | localStorage 不跨设备：旧设备「导出存档」得到 JSON，新设备「导入存档」。 |
| 手机能打开但代码不能真编译 | 属于预期行为；静态托管版一律离线判题，输出会明确标注基线。 |
| 二维码扫不出来 / 地址无效 | 确认填的是完整 `https://...` 且已部署成功；`127.0.0.1`、`localhost`、`file://` 都不能给手机用。 |

## 部署

- **GitHub Pages**：push 后 Settings → Pages → Source 选 GitHub Actions（仓库已带 workflow），或选 `main / root` 手动发布。访问 `https://<用户名>.github.io/<仓库名>/`
- **腾讯云 COS 静态网站 / CloudBase 静态托管 / EdgeOne Pages**：把 `index.html` 放到根目录，构建命令留空、输出目录填 `/`，设默认首页为 `index.html`
- 详细步骤、目录结构与常见问题见 [`部署指南.md`](部署指南.md)

### 一个必须知道的边界

GitHub Pages、COS 等**强制 HTTPS**，浏览器会按 mixed-content 拦掉页面对 `http://127.0.0.1:8787` 的请求。所以托管版会自动降级成「🌐 静态托管版 · 离线判题」：

- ✅ 题库、90 份逐题精讲、代码关断言判分、代码诊所、面试模拟、毕业项目导出、进度存档 —— **全部照常可用**
- ✅ **导入文档（本地生成器）、皮肤主题、音效、自定义音频、题库导入导出** —— 纯前端，托管版同样可用
- ✅ **AI 增强**：填 HTTPS 的 OpenAI 兼容端点即可用（本地生成器仍可作回退）
- ✅ **主动回忆、薄弱诊断、记忆曲线、全局搜索、笔记导出、12 周热力图、语音朗读、题库分享 / Anki / 二维码、PWA 离线与安装** —— 全部纯前端，托管版同样可用
- ⚠️ 只有「真编译」默认不可用，且所有输出都明确标注「基线输出，改动不会生效」，不会假装跑过

想恢复真编译，三选一：

1. 本机 `python3 javac_server.py` 后用 `http://127.0.0.1:8787/` 打开（同源，全功能）
2. 在页面「⚙️ 设置 → 🌐 HTTPS 真编译中继」里填一个 **HTTPS** 的端点（可用附带的 `cloudflare-worker.js` 转发到 Judge0，步骤见部署指南第五节）
3. 直接双击本地 `index.html`（`file://`）也能连本机服务

## 隐私与安全

- 进度、错题、笔记、自定义题库、音效和 AI 配置都存浏览器 `localStorage`，页面不向任何服务器上传学习数据；`.docx` / `.md` 文档也只在浏览器里解析。
- 导入文档、外部分享题库、代码诊所粘贴内容进 DOM 前一律转义，外部 HTML 只会当纯文本显示；分享链接有长度与解压上限。
- 只有填写了 OpenAI 兼容地址 / Judge0 地址时，文档片段或代码才会发往你指定的接口；未配置或调用失败一律回退本地。
- 本地编译服务只监听 `127.0.0.1`，每次请求独立临时目录、带超时与输出截断，请勿暴露到公网。

## 进度存档

进度存在浏览器 `localStorage`，按域名隔离。托管版与本地版互不影响，可用页面内「⬇ 导出存档 / ⬆ 导入存档」迁移。清浏览器缓存、换设备或换域名都会丢进度，记得偶尔备份一份 JSON。
