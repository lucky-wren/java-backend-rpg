🎯 这套东西是按「学会」设计的，不是按「刷完」设计的

· 懂原理：5 幕 14 章共 — 关，全局按 ★1 → ★5 严格递增；三条主线（Java 底座 / 工程与数据 / 业务与交付）逐幕螺旋加深。每一关都有只讲这一题的精讲：本题考什么 → 起因 → 机制逐层推导（含 ASCII 图）→ 真实场景 → 本题踩坑表 → 面试 30 秒怎么说 → 面试官会怎么追问。

· 地图顶部有醒目的「下一关」横幅和难度阶梯；当前关是大号发光圆点，已完成打勾、未解锁灰暗、BOSS 金红，一眼就能分辨状态。

📱 把游戏装到手机主屏幕（通勤随时刷）

装到主屏幕后是全屏、无地址栏、有独立图标的 App 形态，首次联网打开会把全部资源缓存下来，之后地铁、飞机上断网也能答题、看精讲、写代码。
前提：必须有一个 https:// 网址。直接双击本地 HTML（file://）或 http://127.0.0.1:8787/ 打开时，浏览器不提供「安装」能力，而且本机地址手机也访问不到。先按下面「🌐 部署成静态站点」拿到 https 地址，再回来操作。

  3. 如果是用微信/QQ 扫开的，点右上角 ··· →「在浏览器打开」，跳到系统浏览器后再按下面的步骤装（微信内置浏览器不能直接安装）。
  4. 也可以直接把链接发到「文件传输助手」，或手机浏览器手输网址。

① iPhone / iPad（iOS 16 及以上，必须用 Safari）

  1. 用 Safari 打开 https 地址，等页面完全加载（首次会缓存离线资源，约 2~3 秒）。

在微信 / QQ 里打开的：右上角 ··· →「在浏览器打开」，跳到系统浏览器后再按上面做。

③ 电脑（Windows / macOS，Chrome / Edge）

  1. Chrome 打开 https 地址，地址栏最右端会出现一个 ⊕ / 显示器带下箭头的「安装」图标 → 点它 →「安装」。
  2. 或右上角 ⋮ →「投屏、保存和共享」→「安装页面为应用」（Edge 是「应用」→「将此站点安装为应用」）。

🔗 题库分享 · Anki · 离线缓存

· 🔗 题库分享：在「⚙️ 设置」导出 Anki CSV（全量 / 只导错题+标记+笔记，UTF-8 BOM，Excel 与 Anki 都不乱码）；也可用 gzip 压缩把「错题 / 入门 12 题 / 薄弱区域」三种范围塞进 URL #hash 生成分享链接（压缩后约 9~17KB，不上传服务器）。90 关整包 gzip 后约 80KB、会超浏览器 URL 上限，所以选「全部题目」时直接下载完整题库 JSON。

· 🌐 HTTPS 真编译中继：部署包附 cloudflare-worker.js（Judge0 兼容、带超时 / 输出截断 / 来源限制），在设置里填 HTTPS 端点即可让 GitHub Pages 版真跑 javac。

💻 在线写代码 · 真编译运行项目

✅ 真编译：在本机执行 python3 javac_server.py（随页面附带的零依赖脚本，装了 JDK 即可），页面会自动探测 127.0.0.1:8787 并把顶部状态灯切成 🟢。此后代码关、讲义示例、项目实验室的代码都是真的 javac / java 编译运行，展示真实 stdout / stderr / compile_output 与耗时。
✅ 多文件项目 + 测试报告：实验室支持多 .java 文件工程；源码里每条 [PASS] xxx / [FAIL] xxx 会自动汇总成逐条测试报告，测试全绿有额外奖励。
✅ 三态自动回退：本地服务 → 自定义 Judge0 兼容服务 → 离线模拟。离线时所有输出都明确标注「🟡 基线输出，改动不会生效」，不假装跑过。
✅ 静态判题兜底：SQL / MyBatis 形态④ 片段不走编译，按内置断言判分并注明需真实 Spring Boot + 数据库工程。
⚠️ 静态托管版的边界（重要）：GitHub Pages / 腾讯云 COS 等强制 HTTPS，浏览器会按 mixed-content 拦掉页面对 http://127.0.0.1:8787 的请求。所以托管版会自动降级成「🌐 静态托管版 · 离线判题」：题库、逐题精讲、代码关断言、代码诊所、面试模拟、毕业项目导出 全部照常可用，只有「真编译」不可用，且所有输出都明确标注基线、不假装跑过。想恢复真编译有三条路：① 本机 python3 javac_server.py 后用 http://127.0.0.1:8787/ 打开（同源，全功能）；② 在下方填一个 HTTPS 的 Judge0 兼容服务；③ 直接双击本地 HTML（file://）也能连本机服务。
⚠️ 安全边界：浏览器里塞不进 JVM，编译服务只监听 127.0.0.1、每次请求独立临时目录、带超时与输出截断，别暴露到公网。完整 Maven 工程（Netty 网关、MyBatis-Plus、RocketMQ、TDengine）仍需本地 JDK 17 + Maven + Docker。

🔒 隐私与数据安全

· 数据都在本机：进度、错题、笔记、自定义题库、音效和 AI 配置都存浏览器 localStorage，页面不向任何服务器上传学习数据。.docx / .md 文档也只在浏览器里解析。
· 外部内容一律转义：别人发来的分享题库、导入的文档、代码诊所粘贴的片段，进 DOM 前都会经过转义——题干、选项、结算、地图节点、讲义、错题本、热力图、下拉框与所有 data-* 属性都覆盖到了，恶意 HTML 只会当成纯文本显示。分享链接另有 200KB 长度上限与 4MB 解压上限。
· AI 与编译服务由你自己指定：只有填写了 OpenAI 兼容地址时，文档片段才会发往那个接口；只有填写了 Judge0 / Worker 地址时，代码才会发往那个接口。未配置或调用失败一律回退本地，不打断练习。
· 本地编译服务只监听 127.0.0.1，每次请求用独立临时目录，带超时与输出截断。请勿把它暴露到公网。
· 备份：清浏览器缓存、换设备或换域名都会丢进度，记得偶尔用「⚙️ 设置 → 导出存档」存一份 JSON。
